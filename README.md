# X One-Tap Block

X（Twitter）のタイムラインの各ポストに 🚫 ボタンを追加し、1タップでブロックできるようにする userscript。

内部的には「…」メニュー → ブロック → 確認 の3ステップを自動でクリックしているだけで、APIトークン等は一切扱わない。

## インストール

1. Chrome に [Tampermonkey](https://www.tampermonkey.net/) を入れる
2. Tampermonkey のダッシュボードで新規スクリプトを作成し、[x-one-tap-block.user.js](./x-one-tap-block.user.js) の中身を貼り付けて保存

## 挙動

- 各ポストの「…」の左に 🚫 が出る
- タップで即ブロック（確認なし）。途中のメニュー・ダイアログは透明化されるので見た目は1タップ
- ブロックしたポストはその場でタイムラインから非表示
- 自分のポスト／ブロック済みの相手では ⚠️ を出して何もしない
- RT の場合、ブロック対象は元の投稿者（「…」メニューと同じ）

## 注意

- 誤タップしたら相手のプロフィールからブロック解除
- X の DOM（`data-testid`）が変わると動かなくなる可能性あり
